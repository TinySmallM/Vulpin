Client — Документация

Client — это инфраструктурный слой (infra layer) приложения Vulpin, который отвечает за взаимодействие с внешней системной утилитой API

Простыми словами: это мост между нашим Go-приложением

Проблема:
Наше приложение должно получать данные по примеру (модель, версию Android, статус подключения и т.д.). Эти данные хранятся внутри устройств, и единственный способ их получить — выполнить команды в терминале как shell. Это аналог REST-API Client.
